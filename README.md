Sistema de Cardápio em Java

Este é um projeto de console desenvolvido em **Java** utilizando a IDE **Apache NetBeans** para gerenciamento de itens de um cardápio.

Funcionalidades:
* **Adicionar:** Permite cadastrar novos produtos no cardápio.
* **Listar:** Exibe todos os itens salvos com seus detalhes.
* **Pesquisar:** Busca produtos específicos através de termos de texto.

Tecnologias Utilizadas:
* **Java SE** (Java Development Kit)
* **ArrayList** para armazenamento em memória
* **Apache NetBeans** como ambiente de desenvolvimento

Como Executar o Projeto:
1. Clone este repositório ou baixe o código fonte.
2. Abra o **Apache NetBeans**.
3. Vá em `File > Open Project` e selecione a pasta deste projeto.
4. Execute a classe principal (geralmente contém o método `main`).
